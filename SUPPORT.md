
# Support

Need help with an OpenDource project?

We're happy to help where possible.

## Before Asking for Help

Please check:

1. The repository README
2. Project documentation
3. Existing issues
4. Existing discussions
5. Frequently asked questions, if available

Your question may already have an answer.

## Getting Support

For project-specific questions, use the repository's available:

- GitHub Issues
- GitHub Discussions
- Documentation
- Community channels

Use the most appropriate channel for your question.

## Bug Reports

Use the **Bug Report** template when reporting reproducible problems.

Please include enough information for maintainers to understand and reproduce the issue.

## Feature Requests

Use the **Feature Request** template to suggest improvements or new functionality.

Explain the problem you are trying to solve and why the proposed change would be useful.

## Security Issues

Do not report security vulnerabilities through public issues.

Follow the instructions in [SECURITY.md](SECURITY.md).

## Commercial Support

OpenDource projects are primarily community-driven open-source projects.

Unless explicitly stated in a repository, there is no guarantee of dedicated commercial support, response times, or service-level agreements.

Thank you for being part of the OpenDource community.
