# Code of Conduct

## Our Commitment

OpenDource is committed to creating a welcoming, respectful, and constructive community.

We want everyone to be able to participate regardless of their background, experience level, or role in the project.

## Expected Behavior

We expect community members to:

- Be respectful and professional.
- Communicate constructively.
- Give and receive feedback respectfully.
- Assume good intentions.
- Focus criticism on ideas and implementations, not individuals.
- Help maintain a welcoming environment.
- Respect different perspectives and levels of experience.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination
- Personal attacks
- Threats or intimidation
- Trolling or deliberately disruptive behavior
- Publishing private information without permission
- Sexual or inappropriate conduct
- Spam or malicious activity
- Any behavior that makes the community unsafe or hostile

## Project Spaces

This Code of Conduct applies to OpenDource repositories, issues, pull requests, discussions, and other official project spaces.

Individual repositories may have additional community guidelines.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Actions may include:

- Warning the individual
- Removing content
- Closing discussions or issues
- Restricting participation
- Temporarily or permanently banning participation

## Reporting

If you encounter unacceptable behavior, please report it privately to the project maintainers through the appropriate support or security channel.

Please do not create a public issue for sensitive reports.

## Final Note

Open source is built by people.

Treat other contributors with the same respect and professionalism that you expect from them.

Thank you for helping make OpenDource a better community.
